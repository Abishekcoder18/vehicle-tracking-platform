# 🚚 Vehicle Tracking & Fleet Monitoring Platform

A full-stack web application to monitor vehicle fleets, track routes, manage fleet information, and visualize operational data using modern web technologies. The platform will later be enhanced with AI-powered route optimization and predictive maintenance.

---

## 📌 Problem Statement

Develop a full-stack solution where vehicles are tracked, routes are monitored, fleet data is managed using PostgreSQL, and the application is deployed to the cloud.

---

## 🎯 Objectives

- Manage vehicles and fleet information
- Monitor vehicle routes
- Track vehicle status
- Store fleet data securely
- Deploy the application to the cloud
- Extend the platform with AI-based route optimization and predictive maintenance
