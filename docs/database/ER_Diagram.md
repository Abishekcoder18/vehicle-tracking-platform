# Entity Relationship (ER) Diagram

## Purpose

The ER Diagram represents the database structure of the Vehicle Tracking & Fleet Monitoring Platform. It identifies the main entities, their attributes, and the relationships between them.

## Entities

1. Users
2. Vehicles
3. Drivers
4. Trips
5. VehicleLocations
6. RouteHistory
7. Notifications

## Relationships

- One User can manage many Vehicles.
- One Vehicle can have many Trips.
- One Driver can complete many Trips.
- One Vehicle can have many Location records.
- One Trip has one Route History.
- One User can receive many Notifications.
